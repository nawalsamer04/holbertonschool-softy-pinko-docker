# Softy Pinko Docker Project

This project introduces the basics of Docker by creating a simple Docker image using a Dockerfile.

## 📌 Task 0: Create Your First Docker Image

In this task, we create a Docker image based on the latest Ubuntu version. The image performs the following steps:

- Updates the package list using `apt-get update`
- Upgrades installed packages using `apt-get upgrade -y`
- Runs a container that prints "Hello, World!" to the terminal

## 🛠️ Technologies Used

- Docker
- Ubuntu
